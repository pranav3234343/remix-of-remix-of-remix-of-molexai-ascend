The MolexAI API

A clean REST + Python interface to TargetIQ, MolGen, ADMET Predict, and BindSim — all powered by NVIDIA BioNeMo on H100s.

Developer Docs

The MolexAI API

🧬

POST /v1/target/score

Score 20K+ proteins for disease relevance using ESM-2 + BioNeMo embeddings.

⚗️

POST /v1/molgen/generate

Generate N novel, synthesizable molecules conditioned on a binding pocket.

🧪

POST /v1/admet/predict

Predict absorption, toxicity, metabolism for a list of SMILES strings.

🔗

POST /v1/bindsim/dock

GPU-accelerated docking + free-energy via NVIDIA Parabricks.

📊

GET /v1/runs/{id}

Poll job status, fetch results, stream logs from any pipeline run.

🔐

Auth

Bearer tokens via OAuth 2.0. SOC 2-ready audit logs on every call.

Quickstart

Install the Python SDK and run your first generation in under five minutes.

pip install molexai

from molexai import Client
c = Client(api_key="sk_live_...")
mols = c.molgen.generate(target="EGFR_L858R", n=50)
for m in mols: print(m.smiles, m.qed, m.sa)
